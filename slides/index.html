Chạy python katas/qk.py progress rồi mở trang này qua local server để thấy tiến độ thật ở đây.

Vòng lặp học

  • python qk.py — xem đang ở đâu, bài kế tiếp là gì
  • python qk.py next — đọc đề đầy đủ
  • Viết code vào file, lưu lại
  • python qk.py run — chấm ngay, báo đúng dòng sai
  • Bí thì hint (3 mức), thật sự bí mới dùng solution

Chế độ watch (khuyên dùng)

Một terminal chạy python qk.py watch, một cửa sổ VS Code mở file bài tập. Cứ ⌘S là bài tự chấm lại — không phải gõ lệnh nữa.

Terminal
cd katas && python qk.py watch
